# 10-Weeks-Pyhton-Tutorial

A 10-week Python learning tutorial to help Ethiopians, especially beginners, start their programming journey. 

## Goal

To help interested Ethiopians learn the basics of Python, while developing my teaching, communication and problem solving skills.

## Weekly Progress

- ✅ Week 01 - Introduction & Installation
- ✅ Week 02 - Variables, Data Types & User Input
- ✅ Week 03 - Operators

## What You'll Learn
- Python basics
- Problem-solving
- building small projects
